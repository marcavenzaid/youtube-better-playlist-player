Settings

YouTube Data API
Set YOUTUBE_API_KEY in the .env file to have this filled in for you; anything typed here overrides it. Without a key the player reads playlists through a hidden embed, which returns video IDs only. Titles are filled in afterwards, and YouTube caps the embed at roughly 200 items.
Getting a key is free and takes only a couple of minutes
  1. Open console.cloud.google.com and sign in with a Google account.
  2. Create a project, or pick one, in the selector at the top of the page.
  3. APIs & Services → Library, search for YouTube Data API v3, open it and press Enable.
  4. APIs & Services → Credentials → Create credentials → API key.
  5. Copy the key (it starts with AIza) and paste it in the box above, or into .env as YOUTUBE_API_KEY=AIza... and reload.
Worth doing while you are there: Restrict key on the credential and limit it to the YouTube Data API. The free quota is 10,000 units a day, which is far more than this player can spend. Reading a playlist costs one unit per 50 videos.
The key is only ever stored in this browser, and it is sent to googleapis.com and nowhere else. Google's own guide covers the same ground in more detail.
Stored data
Titles are cached in this browser so a reload does not re-fetch them. Resetting clears the playlists, the queue, and everything in here.
